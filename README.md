# Лабораторна робота №18 — «Список справ»

## Запуск
1. Розархівуйте проєкт.
2. Відкрийте `index.html` у браузері.
3. Додавайте, позначайте виконаними та видаляйте справи.

## Реалізовано
- Додавання нових справ.
- Відображення загальної кількості та кількості незавершених справ.
- Позначення справ як виконаних / невиконаних.
- Видалення окремих справ та очищення виконаних.
- Збереження даних у `localStorage`.
- Адаптивне оформлення.

## Публікація через GitHub Pages
1. Створіть репозиторій на GitHub та завантажте до нього `index.html`, `style.css`, `script.js`.
2. Відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** виберіть **Deploy from a branch**.
4. Оберіть гілку `main` та папку `/ (root)`, натисніть **Save**.
5. Після публікації скопіюйте адресу сторінки формату `https://USERNAME.github.io/REPOSITORY/`.

## Дані для звіту
Тема: Створення вебзастосунку «Список справ – 1».
Мета: поглибити та закріпити знання з HTML, CSS, JS; набути практичних навичок зі створення вебзастосунків.

Посилання на живу сторінку та репозиторій потрібно додати після власної публікації на GitHub Pages.
